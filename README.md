# Insurance Risk Analysis Dashboard 📊

## Overview

The **Insurance Risk Analysis Dashboard** is a comprehensive data visualization and analytics project designed to analyze insurance risk patterns, claims data, and customer demographics. This dashboard provides actionable insights for insurance companies to make data-driven decisions regarding risk assessment, pricing strategies, and customer portfolio management.

## Project Objectives

- 📈 **Risk Assessment**: Identify and analyze key risk factors affecting insurance claims
- 💰 **Claims Analysis**: Track and visualize claims patterns, frequency, and severity
- 👥 **Customer Insights**: Understand customer demographics and their correlation with risk profiles
- 📊 **Business Intelligence**: Enable stakeholders to access real-time insights through interactive visualizations
- 🎯 **Decision Support**: Provide data-backed recommendations for underwriting and pricing decisions

## Key Metrics & KPIs

The dashboard tracks the following critical metrics:

- **Claims Frequency**: Number of claims per customer segment
- **Claims Severity**: Average claim amount and outliers
- **Loss Ratio**: Claims paid vs. premiums collected
- **Customer Retention**: Customer lifetime value and churn rates
- **Risk Score**: Composite risk assessment for customers
- **Geographic Distribution**: Claims and premium distribution by region
- **Age & Demographic Analysis**: Risk patterns across customer segments
- **Premium vs. Claims**: Profitability analysis by product line

## Data Overview

The dataset includes:

| Field | Description |
|-------|-------------|
| Customer Demographics | Age, gender, location, occupation |
| Policy Information | Policy type, coverage amount, policy duration |
| Claims Data | Claim amount, claim date, claim type, settlement status |

| Premium Data | Premium amount, frequency, renewal status |

## How to Use

### 1. **Opening the Dashboard**
   - Open the `.pbix` file from the `Powerbi_File` folder using Power BI Desktop

### 2. **Connecting to Data**
   - Update data connections if using a different data source
   - Configure refresh schedules for real-time updates
   - Verify data parameters and credentials

### 3. **Navigating the Dashboard**
   - Use page tabs to switch between different analysis views
   - Click on charts and slicers to filter data
   - Hover over data points for detailed tooltips
   - Use drill-through features for deeper insights

### 4. **Exporting Insights**
   - Export individual visuals as images

   - Generate PDF reports for stakeholder presentations

## Setup Instructions

### Prerequisites
- **Power BI Desktop** (Latest version recommended) or Power BI Pro subscription
- **Microsoft Excel** 2016 or later
- **Data files** from the Dataset folder

### Installation Steps

1. **Clone or Download the Repository**
   ```bash
   git clone https://github.com/Purushothamatmakuri/Insurance_Risk_Analysis_Dashboard.git
   ```

2. **Open Power BI Desktop**
   - Launch Power BI Desktop on your machine

3. **Open the Dashboard File**
   - Navigate to `Powerbi_File` folder
   - Open the `.pbix` file

4. **Update Data Sources (if required)**
   - Go to Home → Transform Data
   - Update file paths or connection strings as needed

5. **Refresh Data**
   - Click Refresh to load the latest data
   - Wait for the data model to update

6. **Explore the Dashboard**
   - Navigate through different pages using tabs
   - Use slicers and filters to analyze specific segments

## Troubleshooting

### Common Issues

**Issue**: Dashboard won't load or shows errors
- **Solution**: Ensure all data files are in the correct location, check file permissions, verify Power BI version compatibility

**Issue**: Data connections are broken
- **Solution**: Refresh the data source connections, verify file paths, check network connectivity

**Issue**: Visualizations show no data
- **Solution**: Verify data source has records, check filter selections, confirm data refresh completed

**Issue**: Slow dashboard performance
- **Solution**: Clear Power BI cache, optimize DAX queries, reduce visual density per page
